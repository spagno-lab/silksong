Memory Lockets

Use alongside the route and checkpoint chapters. Act labels are reference stages, not a strict acquisition order. Mutually exclusive branches and mode-only entries are planning alternatives. Tick journal entries after completing the required notes, not merely discovering the creature.

  • Memory Locket · Far Fields — Act 1 · Map — Far Fields (Pilgrim's Rest) / Blasted Steps: Sold by Mort for 150 Rosaries. If you don't purchase this from Mort, it is sold by Grindle in ACT 3 for 250 Rosaries.
  • Memory Locket · Hunter's March — Act 1 · Map — Hunter's March (Far-right): In a cage at the end of the spiky corridor. Break the cage to pick it up.
  • Memory Locket · Greymoor — Act 1 · Map — Greymoor: On a ledge above a Mitemother.
  • Memory Locket · Greymoor (#2) — Act 2 · Map — Greymoor: Inside Halfway Home.
  • Memory Locket · Bellhart — Act 1 · Map — Bellhart: Sold by Frey for 330 Rosaries.
  • Memory Locket · Bellhart (#2) — Act 3 · Map — Bellhart: Silk Soar into the roof.
  • Memory Locket · Bone Bottom — Act 1 · Map — Bone Bottom: Complete "Volatile Flintbeetles" wish.
  • Memory Locket · The Marrow — Act 1 · Map — The Marrow (Top)
  • Memory Locket · Choral Chambers — Act 2 · Map — Choral Chambers (Grand Bellway): Behind a breakable wall above the Bellway, accessible through the "Exhaust Organ - Underworks" path.
  • Memory Locket · Wormways — Act 1 · Map — Wormways (Bottom-right): Held by a corpse.
  • Memory Locket · Blasted Steps — Act 1 · Map — Blasted Steps: On a narrow platform above the sands.
  • Memory Locket · Underworks — Act 2 · Map — Underworks: In a hidden area towards the left of the confession booth.
  • Memory Locket · Whispering Vaults — Act 2 · Map — Whispering Vaults: At the top of a tunnel.
  • Memory Locket · Bilewater — Act 1 · Map — Bilewater: At the far-left edge of a secret room. Bounce over the infested waters and wall-jump up the vertical space to reach it.
  • Memory Locket · Deep Docks — Act 2 · Map — Deep Docks: Held by a corpse at the bottom of a magma-filled area found behind a breakable wall.
  • Memory Locket · Bilewater (#2) — Act 2 · Map — Bilewater: Held by a corpse in a breakable cocoon dangling from the ceiling.
  • Memory Locket · The Slab — Act 2 · Map — The Slab: Inside the shortcut cave. Look out for a breakable wall as you climb a vertical space.
  • Memory Locket · Memorium — Act 2 · Map — Memorium: After a platforming section.
  • Memory Locket · Far Fields (#2) — Act 3 · Map — Far Fields: In a secret area towards the right of the Karmelita cave. Guarded by a void-powered Skarrgard.
  • Memory Locket · Sands of Karak — Act 2 · Map — Sands of Karak: Held by a corpse at the top of the area.
