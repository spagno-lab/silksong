# What needs another run or a branch copy?

| Content | Why it cannot all coexist |
| --- | --- |
| Three Silkshot versions | A repair permanently chooses one |
| White / red / purple quill | Later colours require skipping earlier quills |
| Pilby funeral / journey / shop death | NPC outcomes replace each other |
| Broodfeast / Runtfeast | Huntress survival and Runt’s branch differ |
| Garmond & Zaza / Shakra Forum help | One helper scene per Forum outcome |
| Different retained Old Hearts | Three are consumed; a different one remains |
| Grindle stealing a chest / claiming that chest yourself | The same loot cannot be taken twice |
| Early normal bosses / later changed encounters | Defeating one removes the opportunity to leave it alive |
| Classic / Steel Soul | Mode-specific NPCs, items, wishes and encounters |

### Steel Soul supplement
Steel Soul includes Steel Seer Zi, Sula, Skynx, A Vassal Lost, Summoned Saviour, Growstone, Shell Satchel, the Chrome Bellhome colour and its mode achievements. Styx and Queen’s Egg belong to Classic instead. Summoned Saviour is not a missing boss you can add to an ordinary Classic save.

The catalogue includes mode labels, but its act assignments are approximate; in particular, do not treat an Act 3 tag as a requirement for Summoned Saviour. [Steel Soul Mode](https://hollowknight.wiki/w/Steel_Soul_Mode_%28Silksong%29)

### Quill alternatives
For red, skip Shakra’s white quill and collect the one on Trobbio’s desk in Act 2. For purple, skip both until Act 3. These are alternatives, not three cumulative collection goals. [Map and Quill](https://hollowknight.wiki/w/Map_and_Quill_%28Silksong%29)

### Achievement planning
Any Silkshot variant qualifies for Arsenal; owning all three is not a single-save requirement. Speedrun achievements, including the five-hour ending and thirty-hour completion targets, are better planned separately from this slow exploration route. A full dialogue-and-scenes playthrough should not race a timer.
